
# Tasca 02 - Historial de versions amb Git

## Descripció

En aquesta activitat s'ha treballat el control de versions amb Git, aprenent a consultar l'historial dels commits i recuperar versions anteriors dels fitxers.

## Continguts treballats

- Bones pràctiques en els missatges dels commits.
- Consulta de l'historial amb git log i git show.
- Recuperació de canvis amb git restore.
- Recuperació de commits amb git revert.
- Eliminació de commits amb git reset.
